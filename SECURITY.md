# Security

This is a static site with no server, accounts or stored user data. The useful things to report are:

- a way to run your own script on the page (XSS), for example through station or song data
- a published file that shouldn't be public, such as a secret or a private file
- a problem in the GitHub Actions deploy workflow

Please report it privately through **Security → Report a vulnerability** on the GitHub repository, rather than in a public issue.

Copyright or takedown requests are not security issues. Open a normal issue for those, as described on the site's [legal page](legal.html#takedown).
